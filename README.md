# 자리배치 LIVE

서버 비용 없이 사용하는 정적 웹앱입니다. 왼쪽 자리표는 화면에 고정되고 오른쪽 125명 명단만 독립적으로 스크롤됩니다.

자리표와 호명 순서 사이의 세로 손잡이를 좌우로 끌면 오른쪽 명단 폭을 조절할 수 있습니다. 손잡이를 두 번 클릭하면 기본 폭으로 돌아갑니다.

## 바로 실행

`index.html`을 Chrome, Edge 또는 Safari로 열면 됩니다. 입력 내용은 현재 브라우저에 자동 저장됩니다.

## 사용 방법

1. `.pdf`, `.xlsx`, `.xls` 또는 `.csv` 명단을 사이트 화면에 끌어놓습니다. `명단 파일 불러오기` 버튼으로 선택해도 됩니다.
2. 이름 옆 자리 칸에 `A9`처럼 입력합니다.
3. 또는 왼쪽 자리표의 원하는 자리 칸에 이름을 직접 입력하고 Enter를 누릅니다. 오른쪽 명단에도 자동으로 반영됩니다.
4. 왼쪽 자리표와 오른쪽 명단은 서로 자동으로 맞춰집니다.
5. 마지막에 `PDF 저장`으로 화면과 같은 교실 배치표를 내려받거나, `엑셀 저장`으로 확정 자리표와 전체 명단을 함께 내려받습니다.

파일에 `호명명단`, `명단`, `호명순서` 등의 시트가 있으면 우선 사용합니다. `이름` 또는 `성명` 열과 `자리` 또는 `좌석` 열을 자동으로 인식합니다.

PDF는 텍스트가 들어 있는 명단을 읽습니다. 스캔 사진만 들어 있는 PDF는 이름을 인식하지 못할 수 있습니다.

## GitHub Pages에 무료로 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더 안의 파일을 저장소 최상단에 업로드합니다.
3. 저장소의 `Settings → Pages`로 이동합니다.
4. `Deploy from a branch`, `main`, `/ (root)`를 선택하고 저장합니다.
5. 표시되는 주소로 접속합니다.

데이터는 서버가 아니라 각 브라우저에 저장됩니다. 다른 사람과 현재 입력 상태를 공유하려면 내려받은 PDF 또는 엑셀 파일을 전달하세요.

## 포함된 외부 라이브러리

- SheetJS Community Edition 0.20.3 (`xlsx.full.min.js`) — 엑셀 파일 읽기 및 저장
- Mozilla PDF.js 6.2.108 (`pdf.min.mjs`, `pdf.worker.min.mjs`) — PDF 텍스트 읽기
- jsPDF 4.2.1 (`jspdf.umd.min.js`) — 확정 자리표 PDF 저장
